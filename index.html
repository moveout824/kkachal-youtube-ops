How it works

데이터는 어디로도
새지 않습니다.

승인부터 활용까지, 모든 단계가 채널 소유자의 통제 안에 있습니다.

소유자 승인 공식 API 로컬 저장 운영 결정
01

소유자가 직접 승인

채널 소유자가 Google 공식 로그인 화면에서 접근 범위를 확인하고 승인합니다. 비밀번호는 누구에게도 공유되지 않습니다.

02

공식 API로만 조회

YouTube Data · Analytics · Reporting API를 통해서만 채널 데이터를 읽습니다. 스크래핑이나 비공식 경로는 쓰지 않습니다.

03

운영자 컴퓨터에만 저장

받은 데이터와 인증 정보는 운영자의 로컬 컴퓨터에만 보관합니다. 별도 서버나 제3자에게 보내지 않습니다.

04

더 재밌는 다음 영상으로

분석 결과는 다음 영상의 대본, 편집, 업로드 전략을 정하는 데만 쓰입니다.

Principles

우리가 지키는 것

01

최소한의 권한

채널 운영에 필요한 범위만 요청합니다. 계정 설정, 소유권, 결제 정보에는 접근하지 않습니다.

02

광고·판매 금지

받은 데이터를 광고에 쓰거나 판매하지 않습니다. Google API 서비스 사용자 데이터 정책을 따릅니다.

03

언제든 철회 가능

소유자는 Google 계정 권한 페이지에서 언제든 접근을 끊을 수 있고, 요청하면 저장된 데이터를 삭제합니다.

04

사람이 최종 결정

공개 상태 변경, 삭제처럼 되돌리기 어려운 작업은 운영자가 직접 확인한 뒤에만 실행합니다.
