개인정보처리방침

시행일: 2026-10-05

1. 수집하는 정보

Kkachal YouTube Ops(이하 "도구")는 채널 소유자가 Google OAuth로 승인한 경우에만, 해당 YouTube 채널의 영상 메타데이터, 댓글, 분석 및 보고서 데이터에 접근합니다. 그 외의 개인정보는 수집하지 않습니다.

2. 이용 목적

수집한 데이터는 채널 운영자가 자기 채널의 성과를 분석하고 영상 정보를 관리하는 용도로만 사용합니다.

3. 보관 및 공유

데이터와 인증 정보는 채널 운영자의 로컬 컴퓨터에만 저장되며, 제3자에게 판매하거나 공유하지 않습니다. 광고 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회

사용자는 언제든지 Google 계정 권한 페이지에서 이 도구의 접근 권한을 철회할 수 있으며, 요청 시 저장된 데이터를 삭제합니다.
