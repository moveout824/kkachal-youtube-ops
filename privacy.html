개인정보처리방침

Kkachal YouTube Ops(이하 "도구")가 어떤 정보에 접근하고, 어떻게 사용·보관·삭제하는지 설명합니다.

시행일 2026-10-05 약 2분 분량
1. 수집하는 정보 2. 이용 목적 3. 보관 및 공유 4. Google API 정책 5. 권한 철회와 삭제 6. 방침 변경 7. 문의

01수집하는 정보

도구는 YouTube 채널 소유자가 Google OAuth로 직접 승인한 경우에만, 해당 채널에 대한 아래 정보에 접근합니다.

  • 영상 메타데이터 (제목, 설명, 태그, 공개 상태 등)
  • 채널 및 영상의 분석·보고서 데이터 (조회수, 시청 시간, 유입 경로, 구독 증감 등)
  • 영상에 달린 공개 댓글

시청자 개인의 계정 정보나 연락처, 채널 소유자의 비밀번호와 결제 정보는 수집하지 않습니다.

02이용 목적

수집한 데이터는 채널 운영자가 자기 채널의 성과를 분석하고 영상 정보를 관리하는 용도로만 사용합니다. 그 외의 목적으로 사용하지 않습니다.

03보관 및 공유

데이터와 인증 정보는 채널 운영자의 로컬 컴퓨터에만 저장되며, 제3자에게 판매하거나 공유하지 않습니다. 광고 목적으로 사용하지 않습니다.

04Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침도 함께 적용됩니다.

05권한 철회와 삭제

사용자는 언제든지 Google 계정 권한 페이지에서 이 도구의 접근 권한을 철회할 수 있습니다. 아래 연락처로 요청하면 저장된 데이터를 삭제합니다.
